課題

なぜフォームUXは
見落とされるのか

コンバージョンの最終関門でありながら、定量的な評価手段がなかった。

手動評価に工数がかかる

専門家によるヒューリスティック評価は数日〜1週間。施策サイクルに間に合わない。

感覚的な議論が続く

「使いにくい気がする」では開発優先度に入らない。スコアがあれば意思決定が変わる。

改修後の比較ができない

リリース前後でUXが改善したか数値で検証する仕組みがない。

01

自動UXスコアリング

ラベル設計・バリデーション・エラーメッセージ・アクセシビリティなど10項目を自動採点。100点満点のスコアで可視化します。

Spring Boot API
02

AIによる改善提案（日本語）

Claude API 連携

OpenPDF
